# libs

These jars are used to compile against and to run the game from IDEA.
They are not committed to git (see `.gitignore`); copy them here from your mods folder:

- `iceandfire-2.1.4.jar` (Ice and Fire CE)
- `uranus-3.0-beta.1.jar`
- `jupiter-2.3.7-1.21.1-neoforge.jar`
- `curios-neoforge-9.5.1+1.21.1.jar`

If you change a version, update the matching `*_jar` line in `gradle.properties`.
